スマートグループ機能について

この機能は、多数のサブフォルダを、名前に含まれる共通のキーワードで自動的にグループ化し、一括で表示/非表示を切り替えるためのものです。

  • グループ候補を作成:
    全てのフォルダ名を分析し、共通して含まれるキーワードを抽出します。
  • キーワードの重要度評価:
    候補の横に表示されるタグは、そのキーワードがなぜ重要と判断されたかを示します。
    囲:【】や「」で囲まれている
    長: フォルダ名の中で一番長い単語
    先頭: フォルダ名の先頭にある
  • ユニークキーワード:
    グループ化されなかったものの、名前が特徴的なフォルダもリスト下部に表示されます。
  • インタラクティブな確認:
    キーワードの行にマウスを乗せると、下のフォルダリストで対象フォルダがハイライトされます。

使い方ガイド

  • フォルダ選択: 左上の「フォルダ選択」から、画像が入った親フォルダを選択してください。サブフォルダも全て読み込まれます。
  • スライドショー: 「再生」ボタンで自動再生を開始します。「シャッフル」ボタンで表示順をランダム化できます。
    • シャッフル OFF: ファイル名順に表示します。
    • シャッフル ON: 全ての画像をごちゃまぜにして表示します。
    • 強化シャッフル: 通常のシャッフルに加え、同じフォルダの画像が連続で表示されにくくなるよう調整します。コレクションに多様性を持たせたい時におすすめです。
  • 表示モード: 用途に応じて様々な表示レイアウトを選択できます。
    • オール: 1枚の画像を画面全体で表示します。
    • アンビアンス: 背景に次の画像がゆっくりと浮かび上がる、環境映像のようなモードです。
    • フォルダ3連: 現在表示中の画像と同じフォルダにある別の画像を2枚、ランダムに並べて表示します。
    • ランダム3連: 全ての画像から完全にランダムで3枚並べて表示します。
    • 横長4連: 横長の画像を表示するのに適した4分割モードです。
    • 横長/縦長画像: それぞれ横長、縦長の画像のみを順番に表示します。
  • フィルター機能: 「フィルターを有効にする」にチェックを入れると、画像分析データに基づいた絞り込みが可能です。
    • ファイル名検索: 入力したキーワードがファイル名に含まれる画像のみを表示します。
    • 肌の露出度: スライダーで肌色成分の割合(%)を指定し、「以上」「以下」で絞り込みます。
    • アクセントカラー: 画像に含まれる主要な色で絞り込みます。「いずれか」は選択した色のどれかを含めばOK、「すべて」は選択した色を全部含んでいる必要があります。
    • 白黒極端画像を非表示: 色情報がほとんどない（無彩色・黒系で構成される）画像を非表示にします。
  • 画像エフェクト: 表示中の画像にリアルタイムで視覚効果を適用します。「⟳」でリセット、「黒化」で色相と階調を反転させます。新しく追加された回転・反転ボタンで画像の向きを調整することもできます。
  • スマートグループ: フォルダ名に共通のキーワード（作家名、シリーズ名など）がある場合に便利な機能です。「グループ候補を作成」でキーワードを自動抽出し、ボタン一つで関連フォルダの選択/除外/単独表示ができます。
  • ショートカット:
    • → / ←: 次/前の画像へ
    • スペースキー: スライドショーの再生/停止
    • Alt + → / Alt + ←: 表示履歴を進む/戻る
    • Mキー: メニューの表示/非表示
    • Sキー: シャッフルモードの切り替え
    • Fキー: フィルターの有効/無効
    • Rキー: 右に90度回転
    • Lキー: 左に90度回転
    • ダブルクリック / Enterキー: 拡大表示モードに切り替え
    • Escapeキー: 拡大表示やモーダルを閉じる

機能の組み合わせについて

複数の設定（フィルター、シャッフル、表示モードなど）を組み合わせた際の挙動は、時に複雑に見えることがあります。基本的な処理の流れを理解すると、より直感的に操作できます。

① フィルターで絞り込み → ② シャッフルで並び替え → ③ 表示モードで表示

① フィルターによる絞り込み
まず、有効になっている全てのフィルター（ファイル名検索、肌の露出度、アクセントカラーなど）が適用され、表示対象となる画像の**母集団**が決定されます。これ以降の処理は、この絞り込まれた画像のリストに対してのみ行われます。
② シャッフルによる並び替え
次に、絞り込まれた画像のリストが、設定されたシャッフルモード（OFF, ON, 強化）に従って並び替えられます。シャッフルOFFの場合は、ファイル名順になります。
③ 表示モードによる表示
最後に、並び替えられたリストを基に、選択された表示モードで画像が表示されます。
具体的な組み合わせの例
  • 例1：「縦長画像」モード + 「シャッフルON」
    この組み合わせでは、まず全ての画像がランダムに並び替えられます。その後、表示する段階で、そのランダムな順序の中から「縦長である」という条件に合う画像を順番に探し出して表示します。そのため、表示される画像は常に縦長ですが、その出現順はランダムになります。
  • 例2：「肌の露出度: 50%以上」フィルター + 「強化シャッフル」 + 「フォルダ3連」
    1. フィルター: まず、全画像の中から「肌の露出度が50%以上」の画像だけが抽出されます。
    2. シャッフル: 次に、その抽出されたリストが「強化シャッフル」のルール（同じフォルダが連続しにくいように）で並び替えられます。
    3. 表示:
      • 中央のメイン画像には、上記のシャッフル済みリストの画像が表示されます（これは必ずフィルター条件を満たしています）。
      • 左右のサブ画像には、メイン画像と**同じフォルダに属する別の画像**が、**元の全画像の中から**ランダムに選ばれて表示されます。
      • ここがポイント: この左右のサブ画像は、フィルター条件（肌の露出度50%以上）を満たしていない可能性があります。「フォルダ3連」はあくまで「同じフォルダの仲間」を紹介する機能であり、フィルターの影響を受けないためです。これにより、意図しない発見があるかもしれません。

このように、各機能がどの段階で影響を及ぼすかを理解することで、「結果が偏る」と感じる現象が、機能の組み合わせによる意図した動作であることがわかります。
