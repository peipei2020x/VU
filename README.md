# Local Viewer Ultimate 改

**サーバー不要で動作する、高機能なブラウザ完結型ローカル画像ビューア**

---

Local Viewer Ultimate 改は、**インストール不要で単一のHTMLファイルとして動作する**、プライバシーを重視した画像ビューアです。ローカルにある大量の画像フォルダを効率的に閲覧・管理・楽しむための多彩な機能を搭載しています。

## ✨ 主な特徴 (Features)

*   **🌐 サーバー不要・完全ローカル動作**: 画像ファイルや分析データが外部に送信されることは一切なく、**プライバシーが完全に保護**されます。
*   **🔌 インストール不要**: ブラウザで開くだけで、すぐに利用を開始できます。
*   **🖼️ 多彩な表示モード**: 単一表示、環境映像風のアンビアンスモード、複数パネル表示など、用途に合わせた**7種類の表示モード**を搭載。
*   **🔎 高度なフィルター機能**:
    *   Web Workerによる非同期処理で、**肌の露出度**や**主要な色（アクセントカラー）**を分析し、それに基づいた絞り込みが可能。
    *   ファイル名検索（正規表現対応）で、目的の画像を素早く見つけられます。
*   **🧠 スマートグループ機能**: フォルダ名を自動で分析し、「作家名」や「シリーズ名」などの共通キーワードでグループ化。関連フォルダを**一括で表示/非表示**にできます。
*   **🎨 豊富な画像エフェクト**: 明るさやコントラストの調整はもちろん、画像の回転や反転も**リアルタイムで適用**できます。
*   **🎲 強化シャッフル**: 通常のランダム表示に加え、**同じフォルダの画像が連続で表示されにくくなるよう調整**するモードを搭載。
*   **⌨️ キーボードショートカット**: ほとんどの主要な操作がキーボードで完結し、快適なブラウジング体験を提供します。

---

## 🚀 使い方 (How to Use)

1.  何かしらの方法で、**このHTMLファイルをブラウザ上で開きます**。
    *   *推奨ブラウザ: Google Chrome, Firefox, Microsoft Edge などのモダンなウェブブラウザ。*
2.  左上の **[フォルダ選択]** ボタンをクリックし、画像が格納されている**親フォルダを選択**します。
    *   サブフォルダ内の画像も再帰的にすべて読み込まれます。
3.  画像の読み込みと分析が開始され、ビューアが利用可能になります。

## 🔧 機能詳細 (Details)

### 表示モード

ドロップダウンから以下の表示モードを選択できます。

*   **オール**: 選択した画像を1枚ずつ画面全体に表示します。
*   **アンビアンス**: 次の画像を背景からゆっくりとフェードインさせる、環境映像のようなモードです。
*   **フォルダ3連**: メイン画像と同じフォルダに属する、他の画像を2枚ランダムに並べて表示します。
*   **ランダム3連**: 全ての画像から完全にランダムで3枚の画像を並べて表示します。
*   **横長4連**: 横長の画像に適した4分割レイアウトで表示します。
*   **横長画像 / 縦長画像**: それぞれアスペクト比が「横長」「縦長」の画像のみを順番に表示します。

### フィルターと絞り込み

「フィルターを有効にする」にチェックを入れると、以下の条件で表示する画像を絞り込めます。

*   **ファイル名検索**: 入力したキーワード（正規表現も可）がファイル名に含まれる画像をフィルタリングします。
*   **肌の露出度**: 画像分析によって算出された肌色成分の割合（%）に基づき、「以上」または「以下」で絞り込みます。
*   **アクセントカラー**: 画像に含まれる主要な色を選択し、「いずれかの色を含む(OR)」または「全ての色を含む(AND)」で絞り込めます。
*   **白黒極端画像を非表示**: モノクロや暗すぎるなど、色情報が乏しい画像を非表示にします。

### スマートグループ

大量のフォルダを効率的に管理するための機能です。

1.  **[グループ候補を作成]** をクリックすると、全フォルダ名を分析し、共通するキーワードを抽出します。
2.  抽出されたキーワード（グループ）に対して、「このグループのみ表示」「このグループを選択」「このグループを除外」といった操作をワンクリックで行えます。
3.  キーワードにマウスオーバーすると、対象となるフォルダがリスト上でハイライトされ、視覚的に確認できます。

### 画像エフェクトと変形

表示中の画像に対して、リアルタイムで以下の効果を適用できます。

*   **回転・反転**: 左右90度回転、上下反転、左右反転が可能です。
*   **カラー調整**: 色合い、彩度、明るさ、コントラストなどをスライダーで直感的に調整できます。
*   **特殊効果**: セピア、グレースケール、ぼかし、透明度なども変更可能です。
*   **[黒化]**: 色相と階調を同時に反転させるユニークなエフェクトです。

## ⌨️ キーボードショートカット (Shortcuts)

| キー | アクション |
| :--- | :--- |
| **→ / ←** | 次/前の画像へ |
| **スペース** | スライドショーの再生/停止 |
| **Alt + → / ←** | 表示履歴を進む/戻る |
| **M** | メニューの表示/非表示 |
| **S** | シャッフルモードの切り替え (OFF → ON → 強化) |
| **F** | フィルターの有効/無効 |
| **R / L** | 画像を右/左に90度回転 |
| **Enter / ダブルクリック** | 画像の拡大表示 |
| **Escape** | 拡大表示や各種モーダルを閉じる |

## 🛠️ 技術スタック (Tech Stack)

*   **HTML5** / **CSS3** (CSS Variables, Flexbox, Grid)
*   **JavaScript (ES6+)**
    *   フレームワークやライブラリに依存しない、いわゆる「**Vanilla JS**」で記述されています。
*   **Web Workers API**
    *   画像の分析処理をバックグラウンドで実行し、UIのフリーズを防ぎます。
